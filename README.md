## 推荐使用方式

1. 先通过英国文学和美国文学两个结构化入口建立文学史时间线。
2. 按时期复习文学背景、文学运动、代表作家与代表作品。
3. 在每个时期的“简化版背诵融合”中集中记忆高频观点、术语和作品线索。
4. 需要核对原文、图片或个人批注时，再回到「文学简化版背」原始导出目录。
5. 结合选段、错题和术语材料进行识别训练，考前按时代、作家和题型建立复习清单。
