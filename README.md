# British and American Literature for YSU Graduate Entrance Exam

燕山大学（YSU）英美文学考研复习知识库。

## 推荐使用方式

1. 先通过英国文学和美国文学两个入口建立文学史时间线。
2. 按时期复习文学背景、文学运动、代表作家与代表作品。
3. 使用「文学简化版背」进行作家、术语和高频知识点的集中记忆。
4. 结合图片、选段和错题材料进行识别训练与查漏补缺。
5. 考前按时代、作家和题型建立自己的最后一轮复习清单。
